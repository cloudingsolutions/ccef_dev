# UX Reference Documents

This folder contains product-facing UX references extracted from design artifacts and prototypes.

These files are source material for product refinement. They do not create implementation scope by themselves. Product commitments are canonical only after they appear in approved slices, use cases, requirements, ADRs, milestones, tasks, or work items.

For prototype-defined screens, downstream agents must inspect `/Users/wolney/repos/projects/ccef-ui-ux/prototype/index.html` and follow its look and feel. They may extrapolate only for screens or states that the prototype does not define, and those extrapolations should stay visually consistent with the prototype.

## Documents

- `prototype-registry.md` - Pinned external prototype revisions and safe access rules for downstream agents.
- `PS-CCEF-001-prototype-ux-reference.md` - UX behavior extracted from the current single-file prototype for the User Access and Account Management Foundation slice.
- `PS-CCEF-001-prototype-traceability.md` - Mapping from prototype areas to product artifacts, including conflicts and refinement questions.
